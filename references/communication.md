# Clear writing and source handling

Use short, active sentences. Keep one instruction or idea in each sentence when
practical. Use the same term for the same thing. Explain an unfamiliar technical
term when it first appears. Preserve official product names, commands, paths,
identifiers, and quoted user language.

Prefer concrete verbs and observable results. Separate confirmed facts, cited
evidence, user decisions, assumptions, recommendations, and open questions. Give
trade-offs in parallel terms so the user can compare choices. Keep detailed
acceptance criteria and architecture rationale even when the prose is concise.

ASD-STE100 is a controlled technical-writing standard. If an authorized current
copy is available, check the applicable rules and approved dictionary while
writing user-facing project material. Record the edition and check scope. If the
standard or dictionary is unavailable, apply only the practical rules above and
say that the text was not formally checked. Do not claim certification or formal
ASD-STE100 compliance from a general style review. Do not bundle or reproduce the
standard's dictionary in this Skill.

Use focused, non-sensitive research for uncertain product assumptions, current
technology choices, installation procedures, and licenses. Prefer primary and
official sources. Record the URL, access date, relevant version, and whether the
conclusion is explicit or inferred. If browsing or domain access is unavailable,
label the item unverified; do not invent evidence.

Optional specialist skills must fit a confirmed need. Select a specific security
skill, such as one from https://github.com/trailofbits/skills, only when the
project needs that capability. Select a browser verification skill, such as
https://github.com/vercel-labs/agent-browser, only for relevant interactive UI
checks when existing browser tools are insufficient. Research its current source,
license, host support, and scope, then include it in the same user choice and
setup receipt. Do not install whole collections by default.
