Project Kickoff

Project Kickoff is a skill for Codex and Claude Code. It asks one question at a time, records your approvals, and writes the approved plan. It then prepares the Agent-Team handoff. It does not write product feature code.

Type $project-kickoff help in Codex or /project-kickoff help in Claude Code.
